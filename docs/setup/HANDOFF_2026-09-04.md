   `[ROZGRYWKA]` (pełny przebieg modali) i główny log `LOG:` z

## Pułapki napotkane w tej sesji

- `gh pr edit` pada z GraphQL Projects (classic) — używać
  `gh api -X PATCH repos/<repo>/pulls/<nr> -F body=@<plik>`, nie `gh pr edit`.
- `node tools/table-tester/scan.mjs --help` → ENOENT: skrypt traktuje `--help`
  jako ścieżkę pliku (brak flagi pomocy).
- Polskie znaki w `grep` bywają zawodne przy transkryptach — do edycji
  `docs/*.md` i przeszukiwania używać `python3` (UTF-8).
- Tester ładuje `dist/`: po każdej zmianie w `src/` wymagany `npm run build`,
  inaczej mierzy się stary artefakt (L76).
