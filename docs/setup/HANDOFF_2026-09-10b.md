## Pułapki środowiska (dopisane w tej sesji)

- **`node --test <plik>` cicho pomija nieistniejące ścieżki** — „przebieg"
  trzech plików może wykonać jeden. Przed powoływaniem się na wynik sprawdzać
  `# tests N` w wyjściu TAP (w tej sesji tak złapany został zły wynik
  „testów pauz").
- **Scryfall: para set/collector ze snapshotu może nie istnieć** (`jvc/214`
  → 404) — nie wolno zakładać, że `rulingsSource` z pary się rozwiąże;
  weryfikować, a przy 404 używać UUID karty.
- W tym shallow-klonie **`origin/<gałąź>` nie istnieje jako ref** — stan zdalny
  sprawdzać przez `git ls-remote origin refs/heads/<gałąź>`, nie `rev-parse`.
- `dist/` gitignorowany — przed Żywym Testerem zawsze `npm run build`;
  `tools/table-tester` wymaga `npm i` po resecie workspace.
- Mutacje `src/`: kopia do `/tmp/mut/*.bak`, przywracanie KOPIĄ, po każdej
  `git status --porcelain` (L8/L13/L136).
