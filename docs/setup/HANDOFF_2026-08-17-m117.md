## Uwagi dla następnej sesji

1. **Pułapka nr 5 z poprzedniego handoffu zadziałała na jego własnym
   autorze** — adres obrazka można wpisać tylko z odpowiedzi Scryfalla.
   Node w sandboxie nie ma sieci; jedyne narzędzie to `fetch_page`. Wygodna
   weryfikacja gotowej karty: `https://api.scryfall.com/cards/<uuid>?format=text`
   — UUID bierze się z adresu obrazka, więc jedno żądanie sprawdza
   jednocześnie tożsamość druku i Oracle.
2. **Zanim dodasz kartę, dodaj jej plik źródłowy** (`docs/cards/`).
   Od M117 pilnuje tego test — karta `supported` bez pliku wywala pakiet.
3. Sandbox nadal potrafi zresetować historię gita (pliki zostają, `.git`
   wraca do commita bazowego). Objaw: push „rejected — fetch first”.
   Naprawa: `git fetch origin <gałąź> && git reset --mixed FETCH_HEAD`.
   W tej sesji reset NIE wystąpił, ale commit+push po każdym zielonym
   kroku zostaje regułą.
4. Uwaga na backticki w komunikacie `git commit -m "…"` — bash wykona je
   jako podpowłokę i wytnie fragment opisu. Dłuższe opisy przez `-F plik`.
