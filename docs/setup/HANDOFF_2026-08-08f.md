## Temat A — Audyt Batch 23 (nieufność właściciela do poprzedniego agenta)

Weryfikacja RUNTIME wszystkich 10 kart (nie asercje definicji): skrypt
end-to-end przez cast/activate/triggers (`node /tmp/audit-b23.mjs`) →
**8/11 przed fixami, 11/11 po**. Trzy realne bugi silnika, które przeszły
przez testy sprawdzające tylko istnienie pól (`def.abilities[0].channel`
itd.):

1. **Greater Tanuki — Channel (ReferenceError).** `activateChannel`
   zadeklarowana WEWNĄTRZ `activateCycling` (abilities.js), wołana
   z `activateAbility` → `ReferenceError: activateChannel is not defined`
   w momencie aktywacji. Dodatkowo emitowała `card_searched` — typ NIEISTNIEJE
   w `EVENT_TYPES` (protocol/types.js) → TypeError przy aktywacji (po fixie
   scope). Fix: funkcja na poziomie modułu + usunięty event `card_searched`
   (`library_searched` już niesie info o szukaniu).
2. **Feedback — „Enchant enchantment" nie do rzucenia.** `legalAuraCasts`
   oferował cel-enchantment, ale 4 miejsca twardo wymagały
   `host.kind === 'creature'`: `castAuraSpell` (resources.js),
   `resolveAuraSpell` (spells.js), `attachAuraToCreature` (attachments.js),
   SBA `removeIllegalAttachments` (attachments.js — aura niszczona co SBA).
   Fix: wspólny helper **`isLegalAuraHost`** (creature / enchantment /
   artifact_or_creature) w attachments.js, użyty w ofercie, walidacji rzutu,
   rozstrzygnięciu i SBA.
3. **Vandalize — tryb „Destroy both" niszczył tylko artefakt.**
   `destroy_permanent` brał `targets[0]` ignorując `effect.targetIndex`
   (konwencja reszty efektów: `targets[effect.targetIndex ?? 0]`). Fix:
   dostosowanie do konwencji.

**Zweryfikowane jako DZIAŁAJĄCE end-to-end (po fixach):** Expunge (destroy +
odrzucenie artefaktu/czarnego), Shiv's (+2/+2 flying + {R} pump), Deepwood

## Temat B — UX: koszty many łamiące się w HTML (zgłoszenie PONOWNE)

- Poprzednia łatka (M51 commit „C", HANDOFF_2026-08-08b) ustawiła `.ms` na
  `inline-block` + `white-space: nowrap` — zapobiega łamaniu WEWNĄTRZ ikony,
  ale NIE MIĘDZY ikonami jednego kosztu (`{2}{W}` = dwa spany). W logu
  dodatkowo `word-break: break-word` (index.html) łamał byle gdzie.
- **Root cause:** sekwencja ikon jednego kosztu nie była atomowa.
- **Fix (bez zamiany ikon na litery):** `mana-icons.js` — `manaSymbolsHtml`
  owija wyjście w `<span class="ms-group">` (tylko gdy ≥1 symbol);
  `index.html` — `.ms-group { display:inline-block; white-space:nowrap;
  word-break:normal; overflow-wrap:normal; vertical-align:-0.12em }` +
  zerowanie skrajnych marginesów ikon. W tekście grupa przenosi się w całości
  do następnej linii; w flex `.action` (przyciski akcji) jest jednym
  flex-itemem.
- Test: `test/mana-icons-group.test.js` (7 testów struktury HTML).
