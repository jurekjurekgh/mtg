## Pułapki środowiska (potwierdzone w tej sesji)

- Repo klonowane **płytko** (`depth=1`): `git diff <PR>^ <PR>` nie zadziała bez
  `git fetch --unshallow origin main`. Do audytu PR używaj dwóch ostatnich
  commitów `main` (squash: `git diff 2a1e79d 6d04551 -- src tools`).
- `gh pr diff <nr> -- ścieżka` nie istnieje („accepts at most 1 arg") — filtruj
  lokalnie przez `git diff <sha>^ <sha> -- <ścieżki>`.
- Bash ucina środek długiego wyjścia (`truncated`) — długie pliki czytaj
  po zakresach linii (`sed -n`) albo kopiuj do pliku i czytaj narzędziem plikowym
  (L78). `docs/LESSONS.md` ma teraz 2138 linii.
- Mutacje weryfikacyjne: kopia bazowa **przed** edycją (`cp` pliku), a nie
  `git checkout` po (L8); przy powtarzalnych wzorcach (`sourceCardId: …`)
  sprawdź, że mutujesz WŁAŚCIWE wystąpienie (`effects.js` ma ich 47) — pierwsza
  próba trafiła w cudze i dała fałszywie zielony wynik (L34).
- Pin na strażniku musi testować tę samą ścieżkę co produkcja: pierwsza wersja
  pina A1 była zielona przy produkcji czytającej surowy plik (wykryła to
  dopiero trzecia mutacja).
