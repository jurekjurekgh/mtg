## 4. Pułapki środowiska dla następnej sesji

- Lokalny klon sandboxa ma cały projekt jako **jeden commit** (`c1324c07`) — brak
  historii przed nim; audyt poprzedniego PR robić przez `gh api`/`gh pr diff` (paginated!),
  nie przez `git log` (L190: `gh api pulls/<n>/files --paginate`).
- `tools/table-tester/` czyta `dist/mtg-table.html`, nie `src/` — po każdej zmianie w
  `src/` wymagane `npm run build` (L76), a przy pierwszym użyciu `npm i` w `tools/table-tester`.
- Testy uruchamiać z przekierowaniem do `.arena/` (ENVIRONMENT §5a); pełny `test:all`
  zajmuje ~10–40 min — odpalać w tle (`start_process`) i sprawdzać `.arena/test-all-final.log`.
- Zmiany regułowe wymagają dosłownego tekstu CR przed kodowaniem (ADR 0030).
