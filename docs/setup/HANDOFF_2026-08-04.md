## Nowe mechaniki generyczne w engine

- **Tokeny za liczbę landów podtypu** — `amount: 'lands_with_subtype_you_control'` + `subtype`
- **Koszt zdolności „Discard a card"** — `cost.discardCard` (deterministycznie najtańsza karta)
- **Koszt zdolności „Remove a counter"** — `cost.removeCounter: { name, amount }`
- **„Destroy target artifact"** — efekt `destroy_permanent` + cel `artifact` (→ grób, odpala dies)
- **Obrażenia w kontrolera** — efekt `damage_to_controller` (nie-cel)
- **Mill celu-gracza** — `mill_cards` czyta `targets[0]`, gdy gracz
- **Warunek statyczny „inny wielokolorowy"** — `condition.controlsAnotherMulticolored`
- **Dodatkowy koszt rzutu „sacrifice a creature"** — `spell.additionalCost.sacrificeCreature`
  (enumeracja po stworach w `legalSpellCasts`, płatność w `castSpell`)
- **Modal „Choose one"** — `spell.modes`; `variableTargets` (1–3 cele) + `stunAmongTargets`
- **Escape** — `spell.escape: { cost, exileCount }`; komenda `cast_escape` (rzut z grobu)
- **„Put a multicolored creature from hand"** — efekt `put_multicolored_creature_from_hand`
  + blokująca decyzja `resolve_hand_creature` (stan `pendingHandCreature`)
- **Hybrid mana** — redukcja do bezbarwnej puli (jak każda karta); `colors`=[W,B,U] dla
  wykrywania wielokolorowości

Nowe typy komend: `cast_escape`, `resolve_hand_creature`. Nowe zdarzenia:
`permanent_destroyed`, `hand_creature_choice_required`, `hand_creature_choice_resolved`
(z polskimi tłumaczeniami w `src/table/session.js`). Tokeny: `token_wolf`, `token_hero`.
