## Naprawy root cause w tej sesji (AGENTS.md — nie maskujemy)

1. **`tryFire` upuszczał kontekst zdarzenia** — triggery z danymi zdarzenia
   (manaSpent, kontroler landa, karta do grobu) odpalały się bez kontekstu
   (Nightshade nie zadawał utraty życia). Fix: `extra` przekazywany do
   `fireTrigger` → `applyEffect` (triggers.js).
2. **`createGameObject`/`addObject` nie niosły nowych deskryptorów** —
   `kicker`/`adventure` ginęły w łańcuchu defineCard → gameObjectDataOf →
   addObject (handoff: „każdy nowy field karty musi przejść przez cały
   łańcuch"). Fix: identity.js + game-state.js addObject.
3. **Oferta equipu obejmowała samo źródło** — animowany sprzęt (Skilled
   Animator) był własnym legalnym celem equip w ofercie, execute odrzucał
   (CR 702.6a). Fix: oferta wyklucza źródło (abilities.js).
4. **Oferty ataku/bloku łamały „can't attack/block alone"** — boty dostawały
   opcje, które execute odrzucał (Ember Beast). Fix: filtry w
   legalAttackerOptions/legalBlockerOptions (combat.js).
5. **`passBoth` w testach przekazywał obiekt gracza zamiast id** (pułapka
   testowa, nie engine).

  Pythona `"` pisz jako `\"`, NIE `\\\"` — to drugie zostawia backslash).

  `fetch_page` agenta (ADR 0010 §2a).

  (ryzyko `git add -A`); `gh pr edit` nie działa — opis PR przez
  `gh api -X PATCH repos/{owner}/{repo}/pulls/N -F body=@plik`.
- Fresh clone → `git fetch origin <branch>` + `git reset --mixed FETCH_HEAD`.
- Benchmark B0: `node tools/benchmark.mjs` (~9 min) — NIE przez `| tail`
  (buforuje cały output do końca); uruchamiaj bez pipe'a albo do pliku.
