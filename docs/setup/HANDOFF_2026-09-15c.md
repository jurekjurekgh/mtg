- **G2 (pre-existing)** — M172/C cytował „CR 509.4" dla okna po blokach; aktualne

## Pułapki / lekcje tej sesji

- **Numer reguły w komentarzu to dług jak kod (L44/L143):** G1 utrwalał
  nieprawdziwy model („510 daje priorytet przed obrażeniami") mimo poprawnej
  logiki — czytelnik przepisze model, nie kod. Cytat CR zawsze z literalnego
  źródła (ADR 0030), miejsce cytowania — z odczytu kontekstu (O5).
- **Podejrzenie dewiacji silnik-vs-CR rozstrzyga odczyt przepływu, nie nagłówki
  kroków:** etykieta `combat_damage` sugerowała okno przed rozdaniem; dopiero
  `closingCombatPassBlocked` + bramki `pendingDamageAssignment` pokazały, że
  modelu odpowiada 509.2+510.1/510.2 — podejrzenie wycofane, nie „naprawione".
- **`mtg.wiki/page/<numer-reguły>` nie istnieje** — literalne sekcje CR są na
  stronach haseł (`/Protection`, `/Combat_damage_step`); yawgatog (438 chunków)
  niepraktyczny do wyrywkowych cytatów.
