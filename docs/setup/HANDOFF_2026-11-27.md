## 4. Wnioski (dopisać do LESSONS przy przeglądzie)

- **L195** (dopisana): wspólny helper kwoty/wyceny musi mieć fallback
  obejmujący WSZYSTKIE zbiory, z których przejmuje wywołania — fallback
  tylko na „główny" zbiór uśpił weto Bell/Pyxis i karę cloaków; pełna
  suita po KAŻDEJ zmianie helpera, nie tylko po zmianie map.
- Audyt rodzinny typów efektów (inwentarz `type:` z card-data + semantyka
  silnika) to tani pełny przegląd klasy „co jeszcze unika wspólnej bramki"
  — po J2 (jedna bramka) warto go powtarzać przy każdym nowym typie
  efektu w katalogu (lista SURE_LIBRARY_DRAIN_AMOUNTS jest domknięciem,
  nie dodatkową gałęzią).
- Znak zera w opisach P/T idzie po KIERUNKU efektu (kary „-X/-0", premie
  „+X/+0") — kontrakt `ptPair` pinują testy `bug-ptpair-description.test.js`.
- Dane kosztów rozstrzygać wyłącznie zrzutem Scryfall
  (`docs/cards/scryfall-<slug>.json`), nie pamięcią treningową (ADR 0030):
