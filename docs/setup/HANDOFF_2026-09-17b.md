   Piny: `test/mana-cylix-costed-source.test.js` A/12 + A/13 (izolacja: HEAD
   bez fixa → A/12 RED).
3. **`038cc50` — kasowanie tokenu nie odpinało załączników** (seed 2030,
   „Załącznik permanent-48 wskazuje nieistniejącego gospodarza token-50”).

   (living weapon); gałąź tokenowa `resolve_library_placement` sprzątała

   kasowaniem; audyt pozostałych miejsc `objects.delete()` czysty. Pin:
   `test/batch42-kart.test.js` D3 (RED bez fixa).

4. **`3453593` — oferta celów zdolności omijała wspólne źródło kandydatów**
   (seed 2030, `illegal_ability: Nielegalny cel: token-16 (hexproof)`).
   Gałęzie „{X}, {T}: cel o sile ≤ X" (Entrancing Lyre) i „any target"
   zdolności NADANEJ przez sprzęt (Blazing Torch) enumerowały pole bitwy
   samodzielnie — oferta zawierała cudzego stwora z hexproof, którego
   `validateTargets` odrzucała (klasa L48/M82). Fix: oba miejsca czytają
   `legalTargetCandidates`; audyt pozostałych gałęzi oferty czysty (własne
   permanentny — hexproof ich nie chroni — albo koszty bez celów). Piny:
   T10 + T11 w `test/mtg-rules-fixes.test.js` (po 1 RED przy cofnięciu fixa).
