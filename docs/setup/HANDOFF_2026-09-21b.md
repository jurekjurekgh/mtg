  bash-only syntax wewnątrz `sh -c` / skryptów `sh` (pętla `sh: 1: Syntax error`
  nie może się powtórzyć); skrypty powłoki z `bash`, edycje plików polskich
  przez `python3` (utf-8).

  przez `attachAuraToCreature`/`attachAuraToPlayer`/`attachEquipmentToCreature`) —

  kopie plików do `/tmp` przed mutacjami; commit + push po każdym zielonym kroku
  (tylko `arena/01a0c390-mtg`).
