## Pułapki sesji (do LESSONS przy następnej okazji — odnotowane tu)

1. **Bliźniacze pętle efektów** w heuristic-bot.js: case `cast_spell`
   i `activate_ability` mają WŁASNE pętle `for (const effect of scoredEffects)`
   i łudząco podobne bloki (`reveal_top_pick*`). Fix B wstawiony przy bloku
   w złym case (test dalej RED) — debug przez `console.error` z `cmd.xValue`
   wskazał właściwą pętlę. Przed wstawieniem w 1700-liniowy case potwierdzić
   granice `case`/`return finish` przez `sed -n` (zamknięcie `cast_spell` :4614).
2. **`libraryLossPenalty` nie nadaje się do EE** (safeMargin 20 karałby zdrowe
   X przy bibliotece 22 wbrew zleceniu właściciela) — właściwy jest
   `drawDeckingPenalty` (bije dopiero przy dnie, CR 121.4/704.5b).
3. `addObject(state, {zone:'library'})` SAM rejestruje id w `state.zones.library`
   — dodatkowy ręczny `push` łamie invariant stref.
4. `gh pr edit` nie aktualizuje opisu (GraphQL classic) — `gh api -X PATCH
   repos/<owner>/<repo>/pulls/<nr> -F body=@plik`.
