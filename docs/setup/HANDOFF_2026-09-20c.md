## Pułapka tej sesji (zmierzona)

**Token GitHub wygasa w środku sesji i nie zawsze odświeża się sam.** Pierwszy
blokada pusha (`b1c66e1`) puściła po ponowieniu — token się odświeżył. Druga
(`9de9f7a`, `2919bf1`, `8a641dc` i kolejne) nie puściła: `gh auth status` →
„The github.com token in GH_TOKEN is no longer valid", `gh api user` →
`Bad credentials`, `git push` → `could not read Username for
'https://github.com'`. Commity są lokalne i bezpieczne (workspace trzyma stan),
ale zasada „push po każdym zielonym kroku" (ADR 0020 C/D) wymaga **ponawiania**
pusha przy każdej okazji i powiedzenia właścicielowi, że GitHub w Arena wymaga
ponownego połączenia. Nie force-pushujemy, nie przenosimy pracy na inną gałąź.
