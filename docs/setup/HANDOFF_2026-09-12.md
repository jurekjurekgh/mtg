## Pułapki środowiska (potwierdzone w tej sesji)

- `curl`/`fetch` z piaskownicy do Scryfall jest zablokowany — sieć mają tylko
  `fetch_page` i `web_search`. Nie ponawiać prób shellowych.
- `fetch_page` potrafi oddać URL z uszkodzonym proxy (SignatureDoesNotMatch).
  Gdy zacznie się psuć, nie ponawiać w kółko — dowód offline zwykle wystarcza
  (tu: 404 z `named?exact=…&set=roe` był rozstrzygający bez kolejnych pobrań).
- Przepisywanie snapshotu MUSI zachować zestaw pól: `test/real-cards-batch29.test.js`
  i `batch30` asertują `object: 'card'`, `oracle_text`, `mana_cost`. W tej sesji
  przepisanie curiosity/expunge/welder-automaton zgubiło `object`/`layout`
  i Batch 29 zaświecił się na czerwono (przywrócone).
- Git w piaskownicy ma refspec tylko dla `main`: `origin/arena/01a0925f-mtg`
  nie istnieje lokalnie, więc stan zdalny sprawdzaj przez
  `git ls-remote origin refs/heads/arena/01a0925f-mtg` (przed każdym pushem).
- Inwarianty stanu: załącznik wymaga `kind: 'aura'` (albo `equipment`) oraz
  istniejącego gospodarza — sam `attachedTo` rzuca `assertStateInvariants`.
- Trigger z tapnięcia odpala się tylko przez `execute` (zdarzenie
  `object_tapped`); goły `spendMana` tapuje bez przetwarzania triggerów.
- **Reset piaskownicy w środku sesji** (potwierdzone 2026-09-12): drzewo robocze
  przetrwało, ale historia gita została sklonowana od nowa — HEAD skoczył na bazę
  `main@a2a5f0d`, a commit, który nie zdążył się wypchnąć, zniknął (pliki zostały
  w drzewie jako modyfikacje). Ratunek: `git fetch origin refs/heads/<branch>` →
  `git reset --mixed FETCH_HEAD` (**nie `--hard`** — w drzewie są niezcommitowane
  pliki) → `git status` pokazuje tylko realną różnicę. Pliki poza repo
  (`/home/user/pr-body.md`, `/home/user/msg.txt`, `/tmp/*`, `.arena/`) **nie
  przetrwały** — opis PR i komunikaty commitów trzeba było odtworzyć.
- Polskie znaki: edycja przez `python3`/`pathlib`, nie `edit_file`; komunikaty
  commitów z pliku poza repo (`/home/user/msg.txt`); `gh pr edit` na tym repo
  nie działa — `gh api -X PATCH repos/jurekjurekgh/mtg/pulls/114 -F body=@plik`.
