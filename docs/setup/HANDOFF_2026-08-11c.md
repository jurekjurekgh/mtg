## Pułapki środowiska (sprawdzone w tej sesji)

- `edit_file` psuje polskie znaki → **python3** Path.read_text/write_text.
- Sandbox potrafi COFNĄĆ lokalny HEAD do main — po każdym commicie push;
  przy rozjeździe `git fetch && git rebase FETCH_HEAD` (nie reset!).
- GH_TOKEN potrafi wygasnąć — reconnect GitHub w Arena; `gh api -X PATCH`.
- Wymagany świeży `npm run build` przed każdym uruchomieniem testera;
  `tools/table-tester/node_modules` kasowane — `cd tools/table-tester && npm i`.
- Zmiana etykiet/logu może psuć testy asertujące stare teksty — `npm test`
  przed commitem (ta sesja: table-ui/table-session).
- `PlayerView.pendingClash.cards` niesie teraz **cardId** (nie objectId) —
  kod/etykiety czytające go po staremu dadzą inny typ.
- `spell_cast`/`spell_countered` niosą teraz LKI `targetCardIds`/
  `counteredByCardId` — nowe logi/e-tykiety mogą z nich korzystać.
