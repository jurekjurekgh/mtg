## Pułapki tej sesji (aktualizacja listy środowiskowej)

- **Fresh clone w połowie sesji zdarzył się ponownie** (podczas pracy):
  lokalne commity znikają z HEAD, ale wypchnięte są na remote — odzyskanie:
  `git fetch origin <gałąź>` + `git reset --mixed FETCH_HEAD`; drzewo
  robocze zachowuje WSZYSTKIE zmiany jako niezatwierdzone. Commit
  wyłącznie lokalny trzeba złożyć ponownie z drzewa (treść można odtworzyć
  z historii rozmowy/komunikatów).
- **Token GH umarł dwa razy w tej sesji** — `gh`/`git push` odrzucają
  („GH_TOKEN is no longer valid" / brak Username). Rozwiązanie: właściciel
  reconnect w Arena. Limit: po reconnect trwa sprawdzać `git ls-remote` —
  trafiony raz na sytuację pośrednią (fresh clone + stary remote).
- **`write_file` NIE działa do `/tmp`** (poza workspace) — skrypty i
  komunikaty commitów trzymać w `/home/user`, nigdy w repo (jednorazowo
  `.commit-msg.tmp` w repo został złapany `git add -A`; naprawa `git rm
  --cached` + amend + `push --force-with-lease` — unikać).
- **edit_file nie znajduje kontekstu przy polskich znakach** — edycje
  plików z PL tekstem robić skryptami `python3` (`io.open(...,
  encoding='utf-8')` działa bezbłędnie).
- Silnik generuje id `grave-${objectSequence}` — testowe `addObject` nie
  mogą używać id `grave-0` itp.; `jumpToStep` nie przyjmuje
  'precombat_main' (użyć helpera mainPhase w teście); sekwencja do cleanup
  to `jumpToStep('end_of_combat')` + 3× passBoth; kolorowa walidacja many
  (PR #28): testy z czarnymi czarami wymagają Swamp.
