   filtrze). Fix w `combat.js`: `lethal = baseLethal` (deathtouch = 1);
   prewencja liczona dopiero przy zadaniu (filtr → tarcze → `dealt`).
2. **CR 119.3** — `damage_dealt` niesie kwotę ZADANĄ (po prewencji) w
   ścieżkach combat atakujący→bloker, bloker→atakujący oraz
   `damage_to_controller`; zdarzenia `damage_prevented` (filtr+tarcze)
   trafiają do strumienia wyniku komendy.
3. **CR 701.27a** — proliferate celuje w graczy z trucizną: `player.poison`
   (nie `player.counters.poison`) w kandydatach i aplikacji.
4. **CR 401.4** — `mill_from_bottom` bierze spód biblioteki GRACZA-CELU
   (ostatnia WŁASNA karta celu we wspólnej liście), nie ostatni element listy
   (Cellar Door młynował kartę drugiego gracza po scry/mulligan-bottom).
5. **CR 108.3/400.7** — `bounce_permanent` wraca na rękę WŁAŚCICIELA
