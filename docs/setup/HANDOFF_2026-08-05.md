- Sandbox blokuje bezpośredni HTTPS (curl/Node fetch) — dane Scryfall i arkusz
  kolekcji przez `fetch_page` agenta.
- Sandbox resetuje HEAD między zdarzeniami (po resecie `git fetch` +
  `git reset --mixed origin/<gałąź-sesji>`); worktree przetrwa.
- Uwierzytelnienie GitHub może umrzeć w trakcie sesji — commituj fragmentami
  pushowanymi od razu.
- Pełny benchmark B0 ~2,5–3 min na 6 taliach singleton; crash = błąd
  engine'a (tej sesji: mill psuł pending-decyzje, infect-0 w combat).
- **Grep po CSV kolekcji:** plik ma 3 kolumny (`Ilustracja,Nazwa Karty,Plan`) —
  nazwa NIE jest na końcu linii; szukaj bez kotwicy `$` (inaczej znajdziesz 0).
- **Testy czytające `state.events`:** resolveTopOfStack pcha zdarzenia
  bezpośrednio, a `pass_priority` ponownie przez zwracany slice — licznik
  zdarzeń rozstrzygnięcia w `state.events` jest podwojony (stan gry i mutacje
  poprawne; konsumenci UI/replay czytają `result.events`, nie `state.events`).
