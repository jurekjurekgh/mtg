  arkusz kolekcji przez narzędzie `fetch_page` agenta.
- Sandbox resetuje HEAD między zdarzeniami (commity po push są na zdalnym;
  po resecie `git fetch` + `git reset --mixed origin/<gałąź-sesji>`),
  worktree przetrwa.
