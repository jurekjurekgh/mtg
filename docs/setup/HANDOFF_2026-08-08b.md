## Co zostało zrobione

### Commit 2 (A) — `feat: opis create_token uwzględnia amount + fateful hour`

**`src/table/render.js`:**

- `describeSpellEffects` (linia 137) — dla `create_token` z `amount > 1`
  zwraca `Stwórz ×N P/T Name`; z `ifLifeAtMost` dokleja `(amountIfCondition
  przy życiu ≤ ifLifeAtMost)`. Bez `amount` (domyślne ETB) — zostaje
  bez prefiksu. Przykłady:
  - Gather the Townsfolk: `Stwórz ×2 1/1 Human (5 przy życiu ≤ 5)`
  - Howl of the Night Pack: `Stwórz ×2 2/2 Wolf` (brak fateful hour)
  - Crested Herdcaller: `Stwórz 3/3 Dinosaur` (amount=1, bez prefiksu)
- `describeEffect` (wewnętrzna) — analogiczna logika `×N`. Sailor
  of Means, Captain's Call, Howl w etykietach „Aktywuj: … (koszt
  {T}): stwórz ×3 token Soldier" zamiast „stwórz token Soldier".

**`test/spell-effect-description.test.js`** — 5 testów: amount=1
bez prefiksu, amount=2 z fateful hour, amount=2 bez fateful hour,
bez jawnego amount, amount=3 w tej samej logice co describeEffect.

### Commit 4 (C) — `fix: ikony many nie łamią tekstu`

**`src/table/index.html`** — reguła `.ms` (linia 56):
- `display: inline-block` (z `inline-flex`) — nie wymusza własnego
  kontekstu łamania linii, ikona trzyma się sąsiedniego tekstu.
- `white-space: nowrap` — ikona nie łamie się sama, zawartość
  (litera) nie zawija się.
- `flex-shrink: 0` — w flexbox .action ikona nie kurczy się,
  więc nie znika w ciasnym buttonie.
- `margin: 0 2px` (z `0 1px`) — więcej odstępu dookoła ikony.
- `text-align: center` — litera wyrównana (inline-block nie robi
  tego automatycznie, w przeciwieństwie do inline-flex).
- `min-width: 1.25em` — dla bezpieczeństwa (gdyby komuś przyszło
  ustawić `width: auto`).
- `line-height: 1.2` (dostosowane do inline-block).
- Komentarz wyjaśniający genezę problemu (screenshot iPada).

Bez zmian w `src/table/mana-icons.js` (helper JS nadal zwraca ten
sam HTML `<span class="ms ...">`. Build wkleja CSS z `index.html`
do `dist/mtg-table.html` (ADR 0011), więc zmiana trafia do artefaktu
przy `npm run build`.

  nowych kart modalnych.

  pełna partia na talii z `your-temple-is-under-attack` (np.

  z czytelnymi nazwami.
