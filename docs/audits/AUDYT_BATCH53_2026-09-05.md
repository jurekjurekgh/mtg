### A1 (reguła, naprawione): Glorifier — refleks gasł po zabiciu źródła

rozstrzygnięciem ofiary) gasił refleks „When you do" — silnik czytał
zdolność ze źródła na stole, a źródło już nie żyło. Ruling LCI: refleks
to dziecko ROZSTRZYGNIĘTEJ zdolności, niezależne od strefy źródła
(CR 603.10). **Naprawa:** zdolność jedzie na ZDARZENIU
(`reflexiveAbility` w `pendingSacrifice` → event), nie jest odczytywana
ze źródła; wyjątek strefowy w `game-state.js`/`triggers.js`. Test:
kill-in-response → ofiara → liczniki i tak lądują (sondy
`/tmp/probe-glory*.mjs`, finalnie 1/1). Klasa: LKI faktów historycznych
(ten sam kanał co F3).

### B1 (kafel, naprawione): koszt plotu bez pipów kolorów

Kafel: „Plot {1}: ..." — goła liczba kłamała, że {1}{W} płaci się

### B2 (odrzucone): kafel zniszczenia bez dopisku o celu

Propozycja dopisku przy destroy-tile — odrzucona: konwencja globalna
kafla zniszczeń (cel w logu i modalu, nie na kaflu). Spójność > lokalny
dopisk.

### B3 (log, naprawione): trigger wielocelowy logował jeden cel

Glorifier „up to two": log pokazywał tylko pierwszy cel. **Fix:**
`cele: A, B` w `session.js` + test (17/17 w pliku przy naprawie).

### B4 (gramatyka, naprawione): „stwórz kopia" → „stwórz kopię"

Błąd odmiany w linii `create_offspring_token`. Test pinu.

### B5 (kafel, naprawione): ewazja Rampagera niewidoczna

Statyka `cantBeBlockedByPower` nie miała reprezentacji — kafel milczał
o kluczowej zdolności. **Fix:** „nie może być blokowany przez stwory
o mocy ≤N" w `describeStatic`. Test pinu.

### B6 (etykieta oferty, naprawione): offspring wyglądał jak zwykły rzut

Wariant `offspring: true` miał IDENTYCZNĄ etykietę jak rzut naturalny —
dwa przyciski o różnym skutku (klasa M101/B). **Fix:** „Zagraj: X (koszt
C + offspring {2})", format jak kicker. Test pinu.

### B7 (odrzucone): log celów bez właściciela („cel: Plains")

konwencja globalna wszystkich linii logu (modale niosą właściciela,
log nie) — naprawa = zmiana blast-radius całego logu. Obserwacja na
przyszły przebieg polerowania logu, nie znalezisko batch53.

## Warstwa (c) — scoring bota (per karta)

Metoda: odczyt gałęzi `scoreCommand` (plot/cast/cel-triggera/ofiara/
aktywacja/walka) + 12 mikrosond headless na prawdziwych definicjach
(`createHeuristicBot.chooseCommand(playerView(...))` + `trace()`).
Sondy uzyskały status testów tylko dla fixów i pinów poprawności
(`test/batch53-bot.test.js`, 6 testów); reszta to obserwacje audytowe.

- **Acidic** — rzut jako ciało 2/2 za 5 (premii ETB brak, C-R1), ale
  WYBÓR CELU wzorowy: artefakt 5/5 wroga (45) > ląd wroga (30) > własny
  ląd (−20); na żywo bot niszczy wrogiego Ramrollera (G15). ✓
- **Keep Out** — tryb + cel wycenione per-wariant: 4/4 (90, lethal)
  > 1/1 (78) > pass. ✓
- **Rust-Shield** — plain/offspring remis 69,3 (jak kicker: brak wyceny
  wariantu → pierwsza oferta; C-R7, konwencja pre-existing). Atak:
  sim NIE ZNAŁ progu ewazji — bot trzymał Rampagera przed murem 0/5
  (C-FIX-2). Po fixie atakuje za 3 (mutacja: stary kod FAIL, nowy PASS).
- **Glorifier** — rzut jako ciało; ofiara „najsłabszy pierwszy":
  artefakt-0 (40) > token 1/1 (37) > 3/3 (31) > skip (0). Zwykle słuszne;
  rogi: nigdy nie rezygnuje (C-R3a), artefakty ślepe na wartość (C-R3b).
  Refleks wielocelowy: matematyka friendly (własne +30+wartość, +25 za
  atakującego; w puste przy samych wrogach — wariant [] wygrywa). ✓
- **Inspiring / Ghirapur** — rzut wygrywa z passem na samym ciele
  (66,6 / 63,9); anthem i token bez premii (C-R1). Bot rzuca Ghirapura
  na żywo (G14). ✓ (z rezerwą C-R1)
- **Ironclad** — rzut jako ciało; cel z grobu: wszystkie warianty 0
  (`objectOnBoard` nie widzi grobu) → bierze NAJSTARSZY, nigdy nie
  rezygnuje. Rezygnacja ≈ nigdy słuszna, więc strata = brak dyskryminacji
  jakości (C-R2; dotyczy też Mystic Sanctuary, Circle Druid, reanimacji).
- **Óin** — loot +8 > pass przy niepustej bibliotece; odrzut najtańszy
  (land przed czarem). ✓ z rezerwą: koszt odrzutu niemodelowany (lekka
  nadaktywność przy ręce pełnej gazu). Lekcja sondowa: pusta biblioteka
  w harnessie dawała −38 (panika deck-out) — artefakt sondy, nie bota.
- **Ichorclaw** — atakuje w pusty stół, trzyma przed 2/2. Sim nie widzi
  pumpu becomes-blocked (C-R4: linia 3/3-zabija-2/2 + trucizna stracona)
  ani wygranej trucizną (C-R5: chip liczony jak życie). Grane poprawnie
  w ramach modelu, model niepełny.
- **Sheriff** — rzut teraz (59,4) > plot (55,0 flat): bot nigdy nie
  plotuje (C-R6). Rzut natychmiastowy jest rozsądny (uczciwe ciało);
  linia plot (darmowy później + reorder) niewyceniona.

### C-FIX-1 (diagnostyka, naprawione): projekcja remisu bez flagi offspring

Remis plain/offspring miał IDENTYCZNE projekcje (`kicker: 0` w obu) —
audyt remisów widział „remis uczciwy". **Fix:** `offspring: 0/1`
w `tieProjection` (1 linia, zero zmiany decyzji). Golden-master
przeżył z dryfem WYŁĄCZNIE haszy (decyzje/scoreSum/chosenKinds bit w bit;
`--write` po weryfikacji diffa).

### C-FIX-2 (taktyka, naprawione): sim walki ignorował ewazję mocową

`attackerCanBeBlocked` znał latanie/menace/`cantBeBlocked`, ale nie próg
mocy — bot trzymał nieblokowalnego Rampagera przed murem 0/5. **Fix:**
eksport `attackerBlockPowerRestriction` z `combat.js` (L41: jedna prawda)
→ pole `cantBeBlockedByPower` w PlayerView (publiczna statyka, ADR 0017)
→ filtr blokerów w simie (moc efektywna power + grantedPower). Test
mutowany (FAIL przed, PASS po) + pin pola widoku.

### Rekomendacje systemowe (bez akcji — poza zakresem batch53)

- **C-R1** `cast_permanent` wycenia CIAŁO − koszt, ale nie premiuje ETB
  (token, destroy, anthem, powrót z grobu). Główna luka wyceny; dotyczy
  wszystkich stworów z ETB. Większy feature (wycena efektów wejścia).
- **C-R2** cele triggerów spoza stołu (grób) remisują do pierwszego
  (Ironclad, Mystic Sanctuary, Circle Druid, reanimacja). Mały fix
  (wartość po koszcie/P-T) — do rozważenia osobnym PR.
- **C-R3** wybór ofiary: (a) opcjonalna ofiara nigdy nie rezygnuje
  (refleks jałowy przy pustym stole); (b) artefakty liczone jako 0
  (cenne artefakty przed tokenami 1/1). Róg Glorifiera.
- **C-R4** sim walki nie modeluje pumpów z triggerów becomes-blocked
  (Ichorclaw). Klasa generyczna („when becomes blocked, gets +N/+N").
- **C-R5** sim walki nie modeluje wygranej trucizną (infect liczony jak
  chip w życie). Niski priorytet (rzadki plan wygranej).
- **C-R6** bot nigdy nie plotuje (55 flat < ciało). Linia plot Sherifa
  (tempo teraz → darmowe ciało + reorder później) niewyceniona.
- **C-R7** bot nigdy nie dopłaca kicker/offspring (remis → pierwsza
  oferta). Konwencja pre-existing; fix = wycena wariantu (powiązane
  z C-R1 dla tokenu offspring).
