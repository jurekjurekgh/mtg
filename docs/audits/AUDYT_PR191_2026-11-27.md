## 1. Zachowane poprawki — weryfikacja

### F-190/3 — Coordinated Maneuver: cel `creature_or_planeswalker` ✓
Oracle (Scryfall, TDM 6): „deals damage equal to the number of creatures you
control to target creature or planeswalker". Typ `creature_or_planeswalker`
istnieje w silniku (`spells.js:335,1594`) i jest już użyty przez inną kartę
(`card-data.js:14373`) — zmiana danych korzysta z istniejącego mechanizmu.
Usunięcie `limitations` i wpisu `brak-planeswalkerow` w `limitations-guard`
spójne. Brak PW w katalogu — nie dowodzi błędu obecnej partii (zgodnie
z przeglądem PR #190).

### F-190/1 — `sacrificeCreatureCandidates`: wielotypowość ✓
Oracle Malevolent Noble (Scryfall, ELD 95): „{2}, Sacrifice an artifact or
another creature". Nowa logika poprawna we wszystkich kombinacjach flag:
`artifactOrAnother` → artefakty (w tym źródło-artefakt) + stwory ≠ źródło;
`another` → stwory ≠ źródło; bez flag → wszystkie stwory (w tym źródło).
Przypadek Vault of Whispers (`kind: 'land'`, `types: ['Artifact','Land']`)
pokryty przez `o.types` (CR 205.2b). Mutacja do starej logiki opartej na
`kind`: RED (1 fail) — pin działa.

### F-190/17 — atomowość zmiennego kosztu (Krumar) ✓ z obserwacją
`validateVariableAbilityCost` w `performActivation` przypięty (mutacja RED).
Wywołanie w `activateAbility` NIE jest przypięte (mutacja GREEN): dla obecnych
kart jest redundantne, bo `performActivation` re-waliduje przed mutacją.
Chronione są wyłącznie gałęzie decyzji oczekujących (discard /
`opponentChoosesTarget`) dla hipotetycznego połączenia manaX/payLifeX
z decyzją kosztu — brak nośnika w katalogu. Obserwacja, nie defekt; kod
nieszkodliwy (jedna linia, wcześniejszy błąd). Testy Krumara (8) zielone.

### F-190/5 — LKI liczników Gutsy ✓
