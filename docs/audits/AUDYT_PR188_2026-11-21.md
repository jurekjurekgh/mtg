## 1. Zmiana kodu: `DYNAMIC_AMOUNT_NOUNS` (render.js)

### 1.1 Logika i zgodność
- Wpis jest **danymi w mapie deskryptorów** (klucz = slug kwoty z definicji
  karty), nie warunkiem po nazwie/ID karty → **zgodne z ADR 0002** (ta sama
  forma co istniejące `lands_you_control` z Batcha 71 i `basic_land_types_you_control`).
- Ścieżka zużycia: `describeEffect` gałąź `damage:` → `noun ?
  \`zada tyle obrażeń, ile ${noun}\`` → fraza **„zada tyle obrażeń, ile instants
  i sorcery w twoim grobie"** — spójna z brzmieniem pozostałych wpisów mapy
  (dopełnienie po polsku, bez angielskiego szumu).
- Trzy konsumenci mapy (linie ~1300, ~1484, ~2210) — ETB z celem też czyta tę
  samą mapę, więc wpis serwuje obie ścieżki (L41: jedno źródło).
- Komentarz „Batch 65 (Blitz of the Thunder-Raptor, IKO)" **zgodny z faktem**:
  karta jest pinowana w `test/real-cards-batch65.test.js` (L56: zweryfikowane
  grepem, nie przyjęte na wiarę).

### 1.2 Root cause i kompletność naprawy
- Naprawiony objaw był **ostatnią warstwą trójstronnej reguły**: engine
  (`effects.js:567` — licznik `instantSorceryGraveyardCount`, CR 608.2h + ruling
  2020-04-17) i wycena bota (`heuristic-bot.js:8208/14724`, PMSSB-60/F1) znały
  slug już od Batcha 65; brakował TYLKO opis warstwy wyświetlacza. Naprawa u root
  cause (wpis w mapie), **bez maskowania**: żadnego nowego wyjątku po karcie,
  żadnego filtra „nie pokazuj slugów".
- **Audyt kompletności mapy (nowa praca E1):** pełna enumeracja stringowych
  `amount:` w `card-data.js` — 11 wystąpień / 10 slugów:
  | Slug | Efekt | Pokrycie |
  |---|---|---|
  | `artifacts_you_control` ×2 | `damage` | `DYNAMIC_AMOUNT_NOUNS` ✓ |
  | `basic_land_types_you_control` | `damage` | `DYNAMIC_AMOUNT_NOUNS` ✓ |
  | `lands_you_control` | `damage` | `DYNAMIC_AMOUNT_NOUNS` ✓ |
  | `instants_and_sorceries_in_your_graveyard` | `damage` | `DYNAMIC_AMOUNT_NOUNS` ✓ (ten PR) |
  | `colors_of_mana_spent` | `damage` | dedykowana gałąź „ile kolorów many wydano na rzut" ✓ |
  | `commander_casts`, `cards_named_in_graveyard`, `lands_with_subtype_you_control`, `mana_from_treasure_spent`, `attacking_creatures_count` | `create_token`/`get_energy` | `DYNAMIC_AMOUNT_LABELS` przez `dynamicAmount` ✓ |

- Słowa kluczowe/efekty/pola `amountFrom`/`amountFromContext` — osobne mapy,
  pokrycie istniejącymi strażnikami (`m179`, `m202/C`, `card-sources-guard`);
