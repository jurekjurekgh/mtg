## 2. Znalezisko F1 (klasa L1/L48) — kreator many oferował odrzucaną komendę

**Objaw:** po stripie zdolności (`abilitiesStripped: true`) `manaSourcesOf`
(widok) nadal oferował `tap_for_mana` dla landu (`isUntappedLandSource`
rozstrzyga przez `getSourceForObject` **obiektu widoku**), a `execute` zwracał
`false` / `illegal_mana_source: Obiekt nie ma zdolności many`.

**Root cause:** `playerView` nie niósł `abilitiesStripped` — fakt publiczny
rozstrzygniętego efektu był niewidoczny dla filtrów UI (L1: „kontroler nie
jest głupi — jest ślepy”), więc `getSourceForObject` na kopii widokowej
trafiał do fallbacku „land = źródło po podtypie”.

**Naprawa (`ff6543c`):** projekcja battlefield niesie `abilitiesStripped`
(warunkowo — tylko gdy `true`; ADR 0017, jak `goaded`/`detained`; bez pól
„na zapas”). Filtr wizarda sam się naprawia przez istniejące bramy
`getSourceForObject`. Anty-over-fix: zwykły land bez flagi i nadal oferowany.

**Dowód:** `test/audyt-pr143-f5b-rodzenstwo.test.js` (testy 1–2); mutacja M-A
(usunięcie flagi z projekcji) → 2 RED.

## 3. Znalezisko F2 (klasa L52) — fabrykacja 1 bezbarwnej z grantu aury

**Objaw:** land, którego JEDYNĄ zdolnością many jest grant aury (strip +
Nature's Embrace: „{T}: Add two mana of any one color.”), przy bare
`tap_for_mana` (bez `grantColor`) dostawał **1 bezbarwną** zamiast 2 many
wybranego koloru — zdolność, która nie istnieje (CR 605.1a).

**Root cause:** `tapLandForMana` liczył `amount = useGrant ? grant : 1` i
`colors = src?.colors ?? []` przy `src = null` (fallback = 1 bezbarwna), a
handler `tap_for_mana` nie przekazywał `cmd.grantColor` (auto-tap przekazywał
zawsze — stąd rozjazd ścieżek).

**Naprawa (`ff6543c`):** `src/grant/useGrant` liczone PRZED mutacją `tapped`;
`!useGrant && !src` → jawny reject z czytelnym powodem (L52 — granica zakresu
odmową, nigdy ciszą); handler `tap_for_mana` (game-state.js) nosi opcjonalne
`grantColor`. Bare tap zwykłego landu nietknięty (własna zdolność → 1 G);
bare tap landu z grantem nadal aktywuje WŁASNĄ zdolność (zachowanie historyczne
zapięte anty-over-fixem).

**Dowód:** testy 3–5 tegoż strażnika; mutacje M-B (bramka OFF → test 3 RED),
M-C (brak passthrough → test 4 RED). Atomowość: reject zostawia land
odkręcony, pulę pustą.

**Źródła regułowe (ADR 0030):** Oracle Nature's Embrace pobrane 2026-09-28
z api.scryfall.com („…it has \"{T}: Add two mana of any one color.\"”;
rulingi WotC: brak) + CR 605.1a/305.6/613.1f (SHA-2026-09-25, cytaty
w strażniku `audyt-pr142-land-strip-mana.test.js`).

## 5. CR-hunt (etap 4b) — rodzina 616.x i licznik tarczy

Obszar nowy wobec potwierdzeń 28b. Pobrano dosłownie z CR 2026-09-25
(nwgarne/mtg-data `rules/cr-raw.txt`): **616.1 + 616.1a–g + 616.2**
(kolejność zastępczych) oraz **122.1c** (licznik tarczy). Kluczowe cytaty:

> **616.1.** „If two or more replacement and/or prevention effects are
> attempting to modify the way an event affects an object or player, the
> affected object's controller (or its owner if it has no controller) or the
> affected player chooses one to apply […] If two or more players have to make
> these choices at the same time, choices are made in APNAP order.”

> **616.1a.** „If any of the replacement and/or prevention effects are
> self-replacement effects (see rule 614.15), one of them **must** be
> chosen.” (616.1g: efekt zdarzenia zewnętrznego przed wewnętrznym.)

> **122.1c.** „One or more shield counters […] create a single replacement
> effect and a single prevention effect […] **"If this permanent would be
> destroyed as the result of an effect, instead remove a shield counter from
> it"** and **"If damage would be dealt to this permanent, prevent that
> damage and remove a shield counter from it."**”

**Werdykt: pozytywny, bez zmian kodu.** Silnik (weryfikacja w kodzie
+ cytatach): wybór efektu zastępczego idzie do **kontrolera** permanentu
(`destroyPermanents` → `pendingReplacementChoice.playerId`, APNAP po ranku
kontrolerów — `destruction.js`); `destroy` nie jest oferowane, gdy istnieje
replacement (must-choose 616.1a — walidacja `chooseDestructionReplacement`
przyjmuje wyłącznie `options`); kolejność destroy-replacements przed
die-replacements = 616.1g; każdy replacement raz (614.5). Bramka licznika
tarczy `cause === 'effect'` **jest trafna dosłownie wobec 122.1c** (SBA
niszczy „not as the result of an effect” — CR 120.5), a drugie ramię
tarczy (prewencja obrażeń) działa przy zadawaniu; komentarz w
`state-based.js:235` cytował poprawny tekst przed naszą weryfikacją.
