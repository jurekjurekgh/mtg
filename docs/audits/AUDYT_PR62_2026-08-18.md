## Engine / ADR 0002 / CR

`src/engine/` nietknięty. Zmiana siedzi w `src/table/session.js` (warstwa opisu).

`hand_top_choice_resolved` (ok. 1070–1074):

```
const card = (e.playerId === HUMAN_ID && e.cardId) ? nameOf(e.cardId) : 'kartę';
return `${whoN(e.playerId)} kładzie ${card} na wierzch biblioteki`;
```

Zgodne z CR 400.2 i wzorcem `card_drawn` / `look_top_resolved`.
Chittering Rats: cel (przeciwnik) kładzie kartę ze **swojej** ręki.
HUMAN gra Rats → BOT kładzie (ukryć). BOT gra Rats → HUMAN kładzie (pokazać).

`hand_top_choice_required` używa `e.sourceCardId` przez `nameOf` — bez literału nazwy karty (ADR 0002).
`hand_top_choice_resolved` **nie** jest w `BOT_MOVE_CARD_EVENTS` — brak wycieku miniaturki (M123).
