## 1. Niezależnie POTWIERDZONE

- **Baseline.** `npm test` (fast core) **5042/5042** (zgodne z README L33),
  `npm run build` exit 0, `dist/mtg-table.html` ~3,44 MB; `node --test
  test/bot-benchmark.test.js` **10/10**. Liczby z handoffu 09-09 (all 5045,
  quick 84,5%) spójne kierunkowo; brama pełna (test:all/quick) na końcu sesji.
- **A4-1 madness `restorePriorityTo` POPRAWNY i dowiedziony.** W
  `game-state.js` ~4026 push do `madnessQueue` bierze
  `pending.restorePriorityTo ?? state.turn.priorityPlayerId`. `pending.
  restorePriorityTo` jest ustawiany przy tworzeniu decyzji odrzucenia
  (helper `batch3`/`pendingDiscardChoice`, test wiersz 63), więc dotyczy
  CELOWANEGO odrzucenia (Mindstab), gdzie źródło czaru i odrzucający to
  różni gracze. Test `A4-1/4` (madness-batch-x3) asertuje
  `state.turn.priorityPlayerId === 'p1'` (źródło) po rezygnacji p2 z madness
  — przy STAREJ ścieżce (fallback na odrzucającego = p2) ten pin byłby RED.
  Fallback `?? state.turn.priorityPlayerId` zachowuje starą semantykę tam,
  gdzie `restorePriorityTo` nie istnieje (ścieżka zwykła, CR 117.3b) — brak
  regresji ścieżki nie-celowanej.
- **A4-4 (a) `reveal_top_to_bottom_order` w `DECK_ARRANGING_EFFECTS`.**
  Stomping Slabs — reveal 7, potem shuffle; dla bot singletona thenDamage
  niedostępne (kopia na stosie, biblioteka zasłonięta), więc efekt = czyste
  przetasowanie, ta sama klasa co scry/surveil. Kwalifikacja generyczna po
  typie efektu — ADR 0002.
- **A4-4 (b) wycena draw zależna od odbiorcy POPRAWNA i generyczna.**
  `isDrawOnly` (efekt = same `draw_cards`) startuje od `score = -1`; w pętli
  wartości `draw_cards` odbiorca liczony po polu `effect.applyTo === 'target'`
  i `cmd.targets[effect.targetIndex]` → self-draw +wartość, opponent-draw
  −wartość. Nic nie rozpoznaje karty po nazwie (pole, nie cardId) — ADR 0002.
  Guard deck-outu (`drawDeckingPenalty`) zostaje przy dobiorze własnym;
  przeciwnik dostaje czysty minus (wybór heurystyczny, nie reguła — odnotowane
  w komentarzu jako prewencyjne). Remisy (L117) i golden-master objęte
  aktualizowanymi pinami `znaleziska-c-deckout` (isDrawOnly słusznie spycha
  Reunion, netto 0 kart, pod rozwój stworami — stary pin utrwalał artefakt
  bazy 50, nie dobrą grę).
- **B5/G1 `faceDownCause` w LKI POPRAWNE.** `rememberLastKnownObject`
  (objects.js) dopisuje `faceDownCause: object.faceDownCause ?? null` —
  LKI to jedyny producent opisu martwego obiektu; producenci przyczyny
  (manifest/cloak/morph) już istnieli (effects.js/permanents.js). Pole dochodzi
  do `playerView` (game-state.js ~5616/5773) i jest czytane przez
  `faceDownCauseTag`/`faceDownLabel` w session.js — martwy manifest nie wraca
  już jako „Morph" (CR 701.40 vs 702.37). Cztery warstwy L21 domknięte.
- **B5/G1 `manifest_dread_required.sourceCardId` POPRAWNE.** Zdarzenie niesie
  teraz źródło decyzji; konsument (session.js, `srcName(e)` — klasa M162/C,
  „Nazwa — opis") czyta je zamiast surowego „manifest dread". Wpis o źródle
  jest jawny (decyzja gracza przed zakryciem, ADR 0017/L137) — bez wycieku.
- **B5/G2/G3 language/UI fixes — root cause, nie maskowanie.** Np.
  `manaEffectLabel` „bezbarwne" (zgoda liczby), matrix buffa viewer-relative
  (Marauder G1 — fraza zależy od `e.playerId`, nie stałej), `satyr_look_resolved`
  trzy rozłączne fakty (Prowler G3: rezygnacja / ukryty wybór / właściciel widzi
  nazwę), „wartość many" zamiast „mana value" (clash, DYNAMIC_PT),
  `cardInfo.spell` ograniczony do `stack|exile` (G2/Membrane — osad czaru aury
  na kaflach w spoczynku nie jest legalnym opisem; przygoda „on an adventure"
  w exile nadal pokazywana). Trigger clause Disa
  (`card_put_into_graveyard_from_nonbattlefield`) z podtypem i „twój cmentarz".
  Każda zmiana ma komentarz łączący ją z konkretnym znaleziskiem audytu.
- **B7 `counter-labels.js` — wspólny moduł poprawnie wpięty.** `COUNTER_LABELS`
  przeniesione z render.js do `src/table/counter-labels.js` (import zwrotny
  session→render dałby cykl — uzasadnione); render.js i session.js czytają
  ten sam słownik przez `counterLabelGen`; **strażnik M126
  (`test/card-sources-guard.test.js` ~368) czytany z nowego pliku** (nie
  duplikat). Kafle i log zbieżne; dodany silnikowy `shield` (spoza bazy) ma
  wpis + dopełniacz.
- **B5/G2 `detectTileRawSlug` — nowy detektor poprawnie wpięty.**
  `TILE_LINE` (RĘKA/MOJE POLA/POLA WROGA/STOS) + `TILE_SNAKE`
  (jedno-podkreślnikowy slug) — łata lukę, którą `SNAKE_CASE_EVENT` (dwa
  podkreślniki) przepuszczał (attach_aura). Dodany do `runDetectors`. Kalibracja
  G1–G4 (brak fałszywych alarmów); strażnik pokryty testem detektora.
- **`card-data.js`** — usunięty tylko redundantny `keywords: ['fabricate']`
  (Glint-Sleeve Artisan): silnik czyta efekt `fabricate` ze zdolności, keyword
  doklejał drugi opis. Skan użyć keyworda `fabricate` nie wykazał innego
  konsumenta wymagającego tego słowa. Katalog/decki nietknięte (ADR 0029).
