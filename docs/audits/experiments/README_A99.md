# A99 — wyłącznie eksperyment, NIE WDRAŻAĆ

`A99_NIE_WDRAZAC.patch` zachowuje stan izolowanego prototypu z bazą `147a2ea`, aby odtworzyć pracę mimo nietrwałego katalogu `.arena`. To nie jest poprawka produkcyjna ani rekomendacja użycia; odtwarzać wyłącznie w odizolowanej kopii. Testy A100–A102 należy skopiować z bieżącej gałęzi, bo powstały po bazie. Patch obejmuje także eksperymentalnie dostosowane testy A94–A97 i sondy A99.

Pomysł: zarejestrować warunek i migawkę źródła przy wyzwoleniu podczas płatności, odroczyć umieszczenie do checkpointu, dołączyć refleks Zoraline i wywołać istniejący ograniczony batch. Takie wyliczenie nazw zdarzeń nie jest ogólnym modelem, a sprawdzenie warunku przy wyzwoleniu nie dowodzi poprawnej ponownej walidacji intervening-if ani LKI przy rozstrzygnięciu. Metody omijające `tryFire`, triggery zdolności many, odmienne decyzje, akcje stanowe, zagnieżdżone decyzje, kontynuacje zaklęć oraz Ward podczas ogłaszania celów nie są udowodnione. Nie należy stosować poprawki bez zaprojektowania całości i sprawdzenia tego zakresu.

W izolacji wymuszone A84/A98/A100/A101/A102 26/26 oraz większy podzbiór 87/87 (w tym zmienione lokalnie asercje i dodatkowe sondy) przechodzą. Uprzednia wersja bez osobnej obsługi refleksu Zoraline dawała A101 2 RED; bez zdarzenia dobrania A102 2 RED mimo pozornie poprawnego pierwszego wyboru. Wcześniejszy szerszy przebieg prototypu: 694 pass, 3 fail, 16 skip — trzy A83 wymagają świadomej analizy, bo rozszerzenie globalnego batcha daje nowy wybór kolejności także poza płatnościami; nie wolno ich po prostu skasować. Ten szerszy przebieg był przed ostatnimi modyfikacjami i nie jest gwarancją ich zgodności.

Mutacje w izolowanym prototypie: pominięcie odroczenia Imp, Forebear, Griffin Guide, Lorescale Coatl oraz refleksu Zoraline daje po 2 RED w odpowiadających A100/A101/A102. Mutacje nie dowodzą pełności rozwiązania; produkcja nie zmieniła się.

Dodatkowy trwały A103 (`test/audyt-pr177-a103-second-draw-apnap.test.js`) pokazuje kolejny brak: Jolrael na drugi dobór omija `tryFire` i woła `queueTriggerToStack` bezpośrednio. Po pomocniczym ustawieniu licznika pierwszego dobrania, rzeczywiste Spellbomb/Scion dają 2 RED zarówno w produkcji, jak i w powyższym prototypie (w prototypie pierwszy wybór może być prawidłowy, ale cały stos nie jest APNAP). Z tego powodu nawet 26/26 na pozostałych kwarantannach nie zamyka audytu.

Odtwarzanie bezpiecznie wyłącznie w kopii (z katalogu głównego repo): `mkdir -p .arena/odtworzenie && git archive 2ae77d8 | tar -x -C .arena/odtworzenie && git apply --no-index --directory=.arena/odtworzenie docs/audits/experiments/A99_NIE_WDRAZAC.patch`.
