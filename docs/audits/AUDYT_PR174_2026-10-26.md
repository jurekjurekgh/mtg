## §2. Przegląd plików produkcyjnych

### 2.1 `src/engine/game-state.js` — F-1 (`paymentReachableMana`)

**Zmiana:** `!e.fromTreasure` w redukcji produkcji many.

**Analiza:** Bliźniacza funkcja `manualManaOfferUnits` (`src/engine/abilities.js`
linia 2050) już pomija `fromTreasure` — komentarz: „Efekty `fromTreasure`
pomijamy — tokeny Skarbów producibleMana i…". Fix w `paymentReachableMana`
przywraca spójność. Root cause: `producibleMana` liczy Skarby jawnie
(M179/E), a pętla ręcznych zdolności dokłada je drugi raz.

**Wniosek: APPROVE** — poprawka u root cause, bez maskowania.

### 2.2 `src/engine/game-state.js` — CR 104.1 (gate kroku)

**Zmiana:** `if (state.status === 'active')` wokół `jumpToStep` w
`resolve_combat` (po deklaracji blokujących).

**Analiza:** Po śmiertelnych obrażeniach bojowych SBA (`player_lost`, 704.5a)
kończy grę (104.1). Bez gate'a `step_advanced` emitowany był po końcu gry.
Cytat dosłowny: „A game ends immediately when a player wins…" (104.1,
cr-raw.txt wyd. 2026-09-25). Gate spójny z `processTriggers` (ta sama
naprawa w triggers.js).

**Wniosek: APPROVE** — poprawka u root cause, test z cytatem CR.

### 2.3 `src/controllers/mana-offer-guards.js` — F-2

**Zmiany:**
1. Usunięty pad `if ((me.mana ?? 0) > units.length)` — dokładał manę
   ograniczoną jako bezbarwną do automatu.
2. Źródła `spendOnly` wykluczone z `autoManaUnits`.
3. Nowa funkcja `restrictedManaUnits` — jednostki many ograniczonej.
4. `castCostOf` zwraca `artifact` (cel wydania jak `spellManaPurpose`).
5. `castBeyondAutoMana` dołącza `restrictedManaUnits` wyłącznie dla artefaktu.

**Analiza:** Podział many na wolną i ograniczoną istnieje w silniku:
`restrictedPool` (resources.js), `restrictedManaBlocked`, `spendOnly`
(game-state.js:6882). Fix przenosi ten sam podział do warstwy kontrolera.
Spójność z `spellManaPurpose` zachowana — `artifact` czyta `object.types`,
tak jak silnik.

**Wniosek: APPROVE** — poprawka u root cause, cel wydania generyczny
(typ Artifact, ADR 0002 — zero rozgałęzień po nazwie karty).

### 2.4 `src/engine/triggers.js` — CR 104.1 (gate triggerów)

**Zmiana:** `if (state.status !== 'active') return [];` na początku
`processTriggers`.

**Analiza:** Po `player_lost` gra nie istnieje — dalsze triggery nie
trafiają na stos. Cytat dosłowny: „A game ends immediately when a player
wins…" (104.1). Objaw: transkrypt Żywego Testera tt-4 pokazywał
„STOS: Zdolność: Relic Robber" po „Przegrywasz".

**Wniosek: APPROVE** — poprawka u root cause, gate na początku funkcji.

### 2.5 `tools/build.mjs` + `tools/module-graph.mjs` — F-4

**Zmiany:**
1. `importAliasBindings(source)` — parsuje `import { a as b } from './x'`,
   zwraca `[{ local: 'b', original: 'a' }]`. Fail-loud na default/namespace
   (ADR 0011: płaski zasięg zna tylko `a`).
2. `stripModuleSyntax` emituje `const b = a;` na początku ciała.
3. `assertNoNameCollisions` sprawdza kolizje aliasów z deklaracjami.

**Analiza:** Pierwszy alias w `src/` (PR #173: `hasManaActivationOffer as
castFiltersApplicable`) ujawnił brak — Node ESM rozwiązuje aliasy, ale
płaski zasięg artefaktu nie. Fix generyczny: każdy alias dostaje `const`.
Test 3 części: A1 (skan builda), A2 (powiązania), A3 (kolizje).

**Wniosek: APPROVE** — poprawka u root cause, fail-loud na nierozpoznany
kształt importu (L52).
