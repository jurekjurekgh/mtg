## Generyczne mechaniki engine (ADR 0002 — zero warunków na nazwę)

1. **Servant** — entersWithCounters + trigger `dies` z `formerCounters` + efekt `add_counter` amount=`former_plus_one_counters` na creature you control.
2. **Gray Slaad** — Adventure (layout adventure): `adventure` descriptor + `cast_adventure` komenda + exile-then-cast-creature (jak plot ale sorcery). Conditional keywords `minCreatureCardsInGraveyard` (static). Mill jako adventure effect.
3. **Ember Beast** — `cantAttackAlone` / `cantBlockAlone` keywords — walidacja w `declareAttackers`/`declareBlockers` (attacker set size ==1 → reject jeśli zawiera restricted).
4. **Kor Sanctifiers** — Kicker `{W}`: `spell.kicker: {cost, effect}` → warianty `cast_permanent` z/bez kickera (jak phyrexian choice ale koszt dodatkowy). ETB `ifKicked` warunek w triggerze.
5. **Irontread Crusher** — Vehicle + Crew 3: `vehicle` flag + `crew: N`, zdolność aktywowana `crew` → `animate_vehicle` until EOT ( jak animacja lądu w M17 ale z tapowaniem creatures o łącznej mocy).
6. **Skilled Animator** — `becomes_creature_as_long_as_source_remains`: efekt linkuje cel do źródła, obiekt dostaje overlay `animatedBySourceId` — usuwany gdy źródło opuści battlefield (state-based).
7. **Withstand** — `prevent_next_damage` z `amount` + cel (any target). Filtr per-object + licznik pozostałego zapobiegania (dekrementowany w `isDamagePrevented`/`markDamage`). Draw jako drugi efekt.
8. **Nightshade Harvester** — trigger `opponent_land_entered` (landfall przeciwny).
9. **True Conviction** — double strike + lifelink hymn. Double strike = dwa przebiegi jak first strike ale stwór z double uderza w obu. Lifelink: heal przy obrażeniach (changeLife) w obu kierunkach combat.
10. **Disa** — (a) put-into-graveyard-not-from-battlefield reanimate (moveObject to battlefield) — nowy trigger `card_put_into_graveyard_from_non_battlefield` z filtrem subtypes Lhurgoyf. (b) combat damage to player → create_token Tarmogoyf (power/tough dynamic = card types in graveyards). Tarmogoyf P = T = typesCount, T+1.
